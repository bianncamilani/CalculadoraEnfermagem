# CalculadoraEnfermagem

Calculadora de Medicação

Aplicação em Python desenvolvida para auxiliar em cálculos básicos utilizados em estudos de administração de medicamentos e conversão de unidades.

## Funcionalidades

- Regra de três simples
- Cálculo de rediluição
- Cálculo de insulina
- Cálculo de penicilina
- Velocidade de infusão em horas
- Velocidade de infusão em minutos
- Conversor de unidades de massa
- Conversor de unidades de volume
- Conversor de unidades de tempo
- Arredondamento de gotas por minuto

## Objetivo

O objetivo do projeto é reunir, em um único menu interativo, fórmulas comuns utilizadas em cálculos de medicação, tornando o processo mais organizado e fácil de consultar durante os estudos.

## Tecnologias utilizadas

- Python
- Interface via terminal

Este projeto tem finalidade educacional e deve ser usado como apoio aos estudos. Os resultados devem sempre ser conferidos com orientação profissional, protocolos institucionais ou materiais oficiais.
